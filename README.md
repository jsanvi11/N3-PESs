# N3-PESs
This repository contains the PES files, NN-STD model and the necessary training/test data for the publication "High-Energy Reaction Dynamics of N3. JingChun Wang, Juan Carlos San Vicente Veliz, and Markus Meuwly. The Journal of Physical Chemistry A 2024 128 (39), 8322-8332. DOI: 10.1021/acs.jpca.4c02841".
